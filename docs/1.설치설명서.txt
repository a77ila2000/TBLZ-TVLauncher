================================================================
TBLZ TV Launcher (The Bride Lin Zhaoming) - 설치 설명서
버전 v1.0.19-release (패키지명: com.tblz.tvlauncher)
================================================================

이 문서는 안드로이드 TV 셋톱박스 및 태블릿에 TBLZ TV Launcher를
설치하고 초기 설정하는 방법을 안내합니다.

----------------------------------------------------------------
0. 지원 기기 및 준비물
----------------------------------------------------------------

지원 기기
  - 안드로이드 TV 셋톱박스 (Mi Box, Homatics, 크롬캐스트 with Google TV, Shield TV 등)
  - Android 7.0(API 24) 이상. 별도 네이티브 `.so`가 없어 ABI 제약 없음

준비물
  - TBLZ-TVLauncher-v1.0.19-release.apk
  - TVING(티빙) 계정 / Wavve(웨이브) 계정

파일 무결성 확인 (PowerShell):
  Get-FileHash .\TBLZ-TVLauncher-v1.0.19-release.apk -Algorithm SHA256
  (출력된 해시값이 TBLZ-TVLauncher-v1.0.19-release.apk.sha256 파일 내용과 일치해야 합니다)


----------------------------------------------------------------
1. APK 설치 방법 (3가지 중 택일)
----------------------------------------------------------------

[방법 A] ADB 네트워크 / USB 명령어로 설치 (가장 추천)
  1) 셋톱박스/태블릿의 설정 -> 개발자 옵션에서 "USB 디버깅" 또는 "네트워크 디버깅"을 켭니다.
  2) PC의 PowerShell 또는 명령 프롬프트에서:
       adb connect <기기IP>:5555
       adb install -r TBLZ-TVLauncher-v1.0.19-release.apk

[방법 B] USB 메모리로 설치
  1) TBLZ-TVLauncher-v1.0.19-release.apk 파일을 USB 메모리에 복사합니다.
  2) TV 셋톱박스/태블릿에 USB를 연결합니다.
  3) 기기에 설치된 파일 관리자(File Commander, X-plore, AnExplorer 등)로 APK를 열어 설치합니다.
     ("출처를 알 수 없는 앱 설치" 허용 필요)

[방법 C] 'Send Files to TV' (SFTTV) 앱으로 전송 및 설치
  1) 스마트폰과 안드로이드 TV에 'Send Files to TV' 앱을 설치합니다.
  2) 스마트폰에서 TV로 APK를 전송한 후, TV의 파일 관리자로 실행하여 설치합니다.


----------------------------------------------------------------
2. 기본 런처(홈 앱) 설정 방법
----------------------------------------------------------------

1) 설치 완료 후 리모컨의 [홈(Home)] 버튼을 누릅니다.
2) 홈 앱 선택 창이 나타나면 `TBLZ TV Launcher`를 선택하고 [항상]을 누릅니다.
3) 만약 선택 창이 뜨지 않는다면:
   - 안드로이드 [설정] -> [앱] -> [기본 앱] -> [홈 앱]으로 이동하여 `TBLZ TV Launcher`를 기본 홈 앱으로 지정합니다.

※ 순정 런처로 되돌리고 싶을 때:
   - 홈 화면의 앱 바로가기 맨 오른쪽 [ 시스템 설정 ] 카드를 누릅니다.
   - [기본 앱] -> [홈 앱]에서 기존 런처를 다시 선택하시면 됩니다.


----------------------------------------------------------------
3. 첫 실행 및 필수 초기 설정
----------------------------------------------------------------

1) TVING / Wavve 계정 로그인:
   - 홈 화면 우측 상단의 [ ⚙ ] 아이콘을 눌러 런처 설정을 엽니다.
   - [ TVING 로그인 ]: TVING 아이디 로그인은 완료까지, 나머지 간편 로그인은 진입까지만 실기기 확인
     * `TVING 로그인`, `CJ ONE 로그인`, `네이버 로그인`, `카카오 로그인`, `Apple 로그인` 중 원하는 버튼을 누릅니다.
     * 로그인 창 상단도 TVING 아이디, CJ ONE, 네이버, 카카오, Apple 순서입니다.
     * 다섯 방식 모두 Mi Box에서 해당 로그인 화면까지 진입하는 것을 확인했습니다.
     * 로그인이 완료되면 재생에 필요한 두 인증값이 분리 저장되어 런처에 자동 연동됩니다.
     * 이미 로그인된 상태에서 로그인 창을 열면 TVING 사이트를 불러와 로그인 상태를 확인한 뒤 자동으로 닫힙니다(약 10초).
     * TVING 인증 토큰(accessToken)은 수명이 짧아, 만료되면 재생할 때 런처가 자동으로 갱신합니다(몇 초 소요).
     * "TVING 인증을 자동으로 갱신하지 못했습니다"라고 나오면 [ TVING 로그인 ]을 다시 열어 주세요.
       그래도 안 되면 TVING 로그아웃 후 다시 로그인하세요.
   - [ Wavve 로그인 ]:
     * 화면의 아이디(이메일)와 비밀번호 입력란에 Wavve 계정 정보를 입력합니다.
     * `[ Wavve 로그인 ]` 버튼을 누르면 즉시 로그인되어 1080p FHD 스트림이 활성화됩니다.
   - 하단의 `[ 저장 ]` 버튼을 눌러 설정을 완료합니다.

2) 부팅 모드 설정:
   - [ ⚙ 런처 설정 ] 다이얼로그의 "부팅 모드"에서 선택할 수 있습니다.
     * `부팅 시 실시간 TV 자동 실행`: 셋톱박스를 켤 때 인터넷 연결을 확인한 후 마지막으로 시청하던 채널을 전체화면으로 즉시 자동 재생합니다. (티비보다 종료했을때 티비처럼 쓰는게 목적이라 넣음)
     * `홈 화면으로 시작`: 런처 메인 홈 화면으로 부팅합니다.

3) 홈 화면에 자주 쓰는 앱 바로가기 등록:
   - 홈 화면 하단의 [ 어플 ] 영역에서 [ 앱 추가 (+) ] 버튼을 누릅니다.
   - 기기에 설치된 전체 앱 목록 팝업이 뜨면, 원하는 앱들을 여러 개 체크한 뒤 [ 확인 ]을 누르면 홈 화면에 한 번에 등록됩니다.
   - 등록된 앱 바로가기 삭제: 앱 카드에서 리모컨 [OK] 버튼을 길게(롱프레스) 누르면 삭제 확인 팝업이 뜨고 바로 제거됩니다.
