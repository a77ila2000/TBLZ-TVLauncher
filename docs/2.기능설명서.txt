================================================================
TBLZ TV Launcher (The Bride Lin Zhaoming) - 기능 설명서
버전 v1.0.19-release (패키지명: com.tblz.tvlauncher)
================================================================

설치 및 기본 설정은 1.설치설명서.txt를 참고하세요.
이 문서는 TBLZ TV Launcher의 실제 구현 기능과 화면별 조작 방식을 상세히 다룹니다.

################################################################
1부. 실시간 TV 통합 엔진
################################################################

----------------------------------------------------------------
1. TVING / Wavve 실시간 360+ 채널 통합
----------------------------------------------------------------

- 지상파, 종편, 케이블, 영화, 스포츠, 예능, 애니메이션, 다큐, 라디오 등 총 360개 이상의 실시간 TV 채널을 통합 제공합니다.
- 채널 목록 및 EPG(현재/다음 방송 제목, 방송 시작/종료 시간, 실시간 진행률)는 실시간 API를 통해 최신 정보로 자동 동기화됩니다.

[Wavve 실시간 엔진]
  - 현재 실측 176개 실시간 채널 및 EPG 스케줄 연동
  - 3시간 편성 구간에서 채널 ID를 찾고 그 채널의 프로그램 목록을 읽어 OSD의 방송 시간과 진행률을 표시
  - 1080p FHD HLS (`AVC-FHD.m3u8`) 초고화질 스트림 직접 디코딩
  - AWS CloudFront 서명 쿠키(`awscookie`) 및 스트리밍 파라미터 완벽 지원
  - [ ⚙ 런처 설정 ]에서 아이디(이메일)와 비밀번호를 입력하여 직접 로그인

[TVING 실시간 엔진]
  - 188~191개 실시간 채널 파싱 (`v2/media/lives`)
  - 편성표 응답의 `schedules`가 없는 채널은 안전하게 건너뛰고 나머지 채널 EPG를 계속 처리
  - Kotlin 기반 Non-DRM HLS 복호화 및 Widevine DRM 라이선스 발급 연동
  - TVING 교육 카테고리(`CG150` - EBS 계열)를 지상파(전체) 카테고리로 통합
  - [ ⚙ 런처 설정 ]에서 TVING 아이디 / CJ ONE / 네이버 / 카카오 / Apple 로그인을 각각 바로 열 수 있음
  - 로그인 완료 시 `_tving_token`과 `Access-Token`을 서로 섞지 않고 자동 연동
  - 현재 TVING 플레이어 규격에 맞춘 `/v3/media/stream/info` query POST 및 Non-DRM HLS 발급
  - 수명이 짧은 accessToken이 만료되면 TVING 사이트가 직접 재발급하게 한 뒤 재생을 1회 자동 재시도
    (로그아웃·재로그인 없이 몇 초 안에 이어서 재생)

[Media3 ExoPlayer 미디어 파이프라인]
  - AndroidX Media3 ExoPlayer 1.3.1 탑재 (HLS, DASH, Core, UI)
  - 별도 네이티브 `.so` 없이 Kotlin/Java 코드로 구성되어 ABI 제약 없음


################################################################
2부. 홈 화면 및 TV UI / UX 구조
################################################################

----------------------------------------------------------------
1. 상단 상태바 (Header Bar)
----------------------------------------------------------------

- 좌측: TV 로고 및 앱 타이틀 `TBLZ TV Launcher (The Bride Lin Zhaoming)`
- 우측: 실시간 디지털 시계 (`HH:mm`) 및 런처 설정 바로가기 버튼 (`[ ⚙ ]`)

----------------------------------------------------------------
2. 실시간 TV 섹션
----------------------------------------------------------------

- **`[ ▦ 모아보기 ]` 카테고리 브라우저 버튼**:
  * 누르면 세부 장르별 카테고리 브라우저 창이 열립니다.

- **실시간 채널 카드 가로 목록**:
  * 채널 썸네일, 플랫폼 뱃지(TVING/WAVVE), 화질 뱃지(FHD), 채널명, 현재 프로그램명, 방송 진행률 바, 즐겨찾기 별표(★) 표시
  * 홈 최초 포커스는 첫 번째 채널 카드이며, 실제 채널이 하나도 없을 때만 `[ ▦ 모아보기 ]`로 이동
  * 리모컨 [OK] 단타: 선택 채널을 전체화면 라이브 플레이어로 즉시 재생
  * 리모컨 [OK] 롱프레스: 선택 채널의 즐겨찾기(★) 등록 / 해제 토글

----------------------------------------------------------------
3. `[ ▦ 모아보기 ]` (카테고리 브라우저 다이얼로그)
----------------------------------------------------------------

- **좌측 사이드바 카테고리 목록**:
  1) ⭐ 즐겨찾기
  2) 📺 전체 채널
  3) 🔴 TVING 전체
  4) 🔵 Wavve 전체
  5) 지상파 (전체) (Wavve 지상파 + TVING 지상파/EBS 통합)
  6) 종합편성 (WAVVE)
  7) 드라마 / 예능
  8) 뉴스 / 경제
  9) 스포츠
  10) 영화 / 시리즈
  11) 홈쇼핑
  12) 어린이 / 키즈 / 애니
  13) 정주행 채널 (WAVVE)
  14) 라디오 / 음악 (WAVVE)
  15) 다큐 / 정보 (TVING)
  (※ 채널이 존재하는 카테고리만 채널 개수와 함께 자동으로 표시됩니다)
  * 모아보기 최초 포커스는 첫 카테고리 `⭐ 즐겨찾기`이며 `[ 닫기 ]`가 아님
  * 리모컨 [뒤로가기] 또는 [홈] 버튼으로 닫힙니다. (런처 설정·TVING 로그인 창도 [홈]으로 함께 닫힘)

- **우측 3열 바둑판 그리드**:
  * 선택된 카테고리의 채널들을 3열 카드로 배열
  * 리모컨 [OK] 단타: 해당 채널 전체화면 재생
  * 리모컨 [OK] 롱프레스: 즐겨찾기(★) 토글
  * 위치 유지 최적화: 즐겨찾기를 롱클릭으로 토글해도 화면 스크롤이나 포커스가 맨 위로 튀지 않고 현재 위치에 그대로 고정됩니다.

----------------------------------------------------------------
4. 전체화면 라이브 플레이어 조작
----------------------------------------------------------------

- **채널 변경**:
  * 리모컨 [상(▲)] / [채널+] 키: 이전 채널로 즉시 전환
  * 리모컨 [하(▼)] / [채널-] 키: 다음 채널로 즉시 전환
  * 초고속 Zapping: 채널 전환 시 불필요한 전체화면 로딩 스피너를 띄우지 않아 빠르고 쾌적하게 채널을 돌려볼 수 있습니다.
- **OSD 방송 정보 패널**:
  * 리모컨 [OK] 단타: 채널명, 프로그램명, EPG 방송 시간대, 진행률 바, 시계, 해상도 등이 표시되는 OSD를 켜거나 끕니다.
- **방송사 판권 제한 안내**:
  * TVING이 판권 제한 코드 `080`을 반환하면 이전 채널 영상을 즉시 멈추고 재시도하지 않습니다.
  * 판권 제한 안내만 표시하며 네트워크 오류 문구를 함께 표시하지 않습니다. 위/아래 키로 다른 채널을 선택하면 바로 재생을 시도합니다.
- **즐겨찾기 토글**:
  * 리모컨 [OK] 롱프레스: 현재 시청 중인 채널을 즉시 즐겨찾기(★)로 등록하거나 해제합니다.
- **나가기**:
  * 리모컨 [뒤로가기(Back)] 키: OSD가 열려 있으면 OSD 닫기, OSD가 닫혀 있으면 홈 런처로 복귀합니다.

----------------------------------------------------------------
5. 어플 (앱 런처) 섹션
----------------------------------------------------------------

- **사용자 앱 바로가기 목록**:
  * 홈 화면을 깔끔하게 유지할 수 있도록 사용자가 등록한 앱만 표시됩니다.
  * 리모컨 [OK] 단타: 해당 앱 실행
  * 리모컨 [OK] 롱프레스: 바로가기 삭제 팝업 -> 홈 화면에서 제거

- **액션 카드 (목록 우측 고정)**:
  1) `[ 앱 추가 (+) ]`: 기기에 설치된 앱 목록에서 체크박스로 여러 개를 선택하여 홈 화면에 한 번에 추가
  2) `[ 📱 모든 앱 ]`: 설치된 전체 앱을 4열 바둑판 그리드로 탐색 및 실행
  3) `[ 시스템 설정 ]`: Android 시스템 설정 열기

----------------------------------------------------------------
6. 부팅 직행 모드 및 시스템 편의 기능
----------------------------------------------------------------

- **부팅 시 실시간 TV 자동 실행**:
  * 셋톱박스 전원을 켤 때 `BootReceiver`가 네트워크 연결(인터넷 가능 + IP 주소 획득)을 확인한 후, 마지막으로 시청하던 채널을 전체화면으로 자동 재생합니다.
  * [ ⚙ 런처 설정 ]에서 실시간 TV 자동 실행 또는 홈 화면으로 시작 중 선택 가능합니다.
- **원클릭 [ 초기화 ] 기능**:
  * [ ⚙ 런처 설정 ] 창 좌측 하단의 [ 초기화 ] 버튼으로 계정 로그인, 즐겨찾기, 홈 앱 바로가기 설정을 한 번에 초기화할 수 있습니다.
