# v1.0.26 디자인 정리

2026-11-14. 네이티브 Android XML UI를 유지한 디자인 업데이트입니다. [v1.0.26 릴리스](https://github.com/a77ila2000/TBLZ-TVLauncher/releases/tag/v1.0.26)에서 APK와 SHA-256 파일을 받을 수 있습니다.

## 적용한 디자인 자료

- [Taste Skill](https://github.com/Leonxlnx/taste-skill): 하나의 시각 체계, 정렬, 여백과 실제 렌더링 확인.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): 어두운 미디어 UI, 글자 대비, 원격 입력 포커스와 일관된 상태 표시. `video streaming television` 디자인 검색 결과를 TV 네이티브 화면에 맞게 적용했습니다.
- [Jakub Krehel's Design Skills](https://github.com/jakubkrehel/skills): better-ui, better-layout, better-typography, better-colors, better-accessibility, better-writing의 관련 지침.

웹 전용 히어로, 스크롤 애니메이션, 프레임워크 교체는 적용하지 않았습니다. TV의 채널 행, 리모컨 조작과 기존 기능이 우선입니다. 웹 전용 자동 평가를 통과했다고 주장하지 않습니다. 지침은 이번 작업의 참고 사본으로 읽었고 전역 스킬 설정을 변경하지 않았습니다.

## 변경 범위

- 차콜 배경과 밝은 글자, 절제된 청회색 포인트를 공통 색상 토큰으로 통일.
- 채널 카드의 강한 청록색 테두리를 밝은 2dp 포커스로 변경. 편집 중인 앱은 금색, 삭제는 붉은색으로 구분.
- 버튼·탭·입력란·라디오 항목의 모서리와 포커스 상태 정리.
- 홈 제목을 TBLZ TV로 단순화하고 장식용 부제는 숨김. 앱 바로가기 아래 여백 유지.
- 제약 조건이 빠져 겹치던 모아보기 버튼을 우측에 정렬해 기존 필터 탭이 정상 표시되도록 배치 수정.
- 프로그램 설명 글자 12sp → 13sp, 모아보기 안내 문구 간결화.
- 설정 및 모아보기 패널 배경을 불투명하게 변경해 뒤 화면의 글자와 겹침 방지.

디자인 작업 직전 v1.0.25 로컬 수정본과 비교한 Kotlin 파일 28개의 해시는 모두 동일합니다. 공개 v1.0.19 이후의 채널 순환·앱 편집 수정은 이번 릴리스에도 포함됩니다. 스트림 요청, 로그인, 즐겨찾기 범위, 리모컨 키 처리, 무한 순환 및 앱 순서 저장 로직은 변경하지 않았습니다. 외부 글꼴이나 런타임 라이브러리를 추가하지 않았습니다.

## 검증

TiVo Stream 4K / Android 12 / 1920×1080 화면에서 기존 앱 서명을 유지한 업데이트 설치를 완료했습니다. 실제 주소·계정·키 파일은 이 문서에 포함하지 않습니다.

- 단위 테스트 25개 통과: 채널 선택 10, 채널 행 순환 10, 앱 순서 5.
- release 빌드 및 lintVital 통과.
- 좌우 각 80회, 합계 160회 채널 이동 후 포커스가 채널 카드에 유지됨. 수집 구간에 행 이탈 경고와 치명적 예외 없음.
- 앱 길게 누르기 편집, 좌우 이동, 위쪽 X 포커스, 뒤로 취소 후 원래 순서 복구 확인. 실제 삭제는 하지 않음.
- 홈, 모아보기, 설정과 편집 상태를 기기 캡처로 확인. 로그인 상태·즐겨찾기 20개·기존 앱 순서 유지.
- 일반 글자 대비 16.58:1, 포커스 카드 글자 11.36:1, 보조 글자 최소 6.25:1, 밝은 버튼 글자 14.15:1, 포커스 테두리 9.94:1.

이번 검증은 ADB로 보낸 방향키와 화면 캡처를 포함합니다. 사용자의 실물 리모컨 재시험, 다른 해상도·글자 확대·화면 읽기 도구 및 모든 OTT의 영상·소리는 이번 디자인 작업에서 새로 검증하지 않았습니다. 선택형 glance CLI는 설치돼 있지 않아 사용하지 않았으며, 기본 이미지 뷰어와 vision-skills의 dominant_colors 도구로 렌더링과 배경색을 확인했습니다.

## 되돌리기

이 디자인 변경 전 리소스 사본은 로컬 검증 폴더에 보존했습니다. 색상·drawable·layout·style 변경을 되돌려 다시 빌드할 수 있습니다. 기존 버전 APK의 다운그레이드 허용 여부는 기기 정책에 따라 다르므로 앱 데이터 삭제를 동반하는 재설치를 기본 복구 방법으로 안내하지 않습니다.
